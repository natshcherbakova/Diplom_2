## Задание 2: API-тесты

### Автотесты для учебного сервиса «Stellar Burgers»

«Stellar Burgers» — учебный веб-сервис для заказа бургеров.

В проекте реализованы API-автотесты с использованием Requests, pytest и Allure.

### Реализованные сценарии

* создание уникального пользователя;
* создание уже зарегистрированного пользователя;
* создание пользователя без обязательного поля;
* авторизация существующего пользователя;
* авторизация с неверными данными;
* изменение данных пользователя с авторизацией;
* изменение данных пользователя без авторизации;
* создание заказа с авторизацией;
* создание заказа без авторизации;
* создание заказа без ингредиентов;
* создание заказа с невалидным хэшем ингредиента;
* получение заказов авторизованного пользователя;
* получение заказов неавторизованного пользователя.

### Структура проекта

- `data.py` — тестовые данные для создания и авторизации пользователя, изменения данных пользователя, создания заказа и проверки ошибок API
- `conftest.py` — фикстуры pytest для удаления созданного пользователя после выполнения теста
- `urls.py` — базовый URL сервиса
- `endpoints.py` — API-ручки, используемые в тестах
- `requirements.txt` — зависимости проекта и их версии

- `methods` — методы для выполнения API-запросов:
  - `user_methods.py` — методы создания, изменения и удаления пользователя
  - `auth_methods.py` — метод авторизации пользователя
  - `order_methods.py` — методы создания заказа и получения заказов пользователя

- `tests` — каталог с автотестами:
  - `test_create_user.py` — класс `TestCreateUser` с тестами создания пользователя, создания дубликата и создания пользователя без обязательного поля
  - `test_login_user.py` — класс `TestLoginUser` с тестами успешной авторизации пользователя и авторизации с неверными данными
  - `test_update_user.py` — класс `TestUpdateUser` с тестами изменения данных пользователя с авторизацией и без авторизации
  - `test_create_order.py` — класс `TestCreateOrder` с тестами создания заказа с авторизацией, без авторизации, без ингредиентов и с невалидным хэшем ингредиента
  - `test_get_user_orders.py` — класс `TestGetUserOrders` с тестами получения заказов авторизованного и неавторизованного пользователя

### Запуск автотестов

Установка зависимостей:

```bash
pip install -r requirements.txt
```

Для запуска всех автотестов с сохранением результатов для Allure:

```bash
pytest tests --alluredir=allure_results
```

Для просмотра отчёта о пройденном тестовом прогоне:

```bash
allure serve allure_results
```

Для генерации статического отчёта:

```bash
allure generate allure_results -o allure-report --clean
```
